## 검증 범위와 남은 확인

Windows에서 Worker 로컬 실행이 종료되어, 게시된 서버 API를 별도로 검증했다. 페이지 UI는 서버가 반환한 HTML과 동일한 빌드 자산을 쓰는 읽기 전용 로컬 미리보기에서 모바일 가로 넘침·신청 폼·설명 버튼을 검수했다. 최종 게시 페이지도 브라우저에서 직접 열어 제목 줄바꿈과 배치를 확인했다. API 저장 검증은 가상 신청으로 수행했다.

스프레드시트 렌더러가 간단한 영문 셀조차 렌더 시작 직후 종료되는 환경 문제로 **XLSX 전체 시트의 이미지 검수는 완료하지 못했다**. 수식·입력 자료·내보내기는 검증했으며 실제 Excel에서 열어 레이아웃을 한 번 확인해야 한다.

공개 모집 전에 가상 신청 삭제와 실제 운영자의 조회·삭제 경로, 본인 정보로 신청→설치 안내 동선을 확인한다. 가격 제안과 실제 결제는 별도 지표이며 모든 수치는 실제 기록만 넣는다.
