# 쌓이다 배포와 유료 20가족 — 하루 2시간 운영

기준일: 2026-10-13, 한국 시간. 확정 목표는 **쌓이다를 배포하고, 반복 사용을 확인한 뒤 실제 유료 고객 20가족을 확보한다**이다. 기존 첫 사용 100가족 목표를 대체한다. 마케팅 실행 키트의 자료를 활용하되 일정·우선순위·하루 가용 시간은 이 문서를 따른다.

## 목표와 집계

- 배포 목표: 우선 Android Google Play 정식 배포. 기존 프로젝트의 Android 우선 계획을 따른 가정이며, 사용자가 플랫폼을 변경하면 조정한다.
- 사업 목표: 실제 제공하는 유료 상품에 결제한 고유 부모 계정 20개. 부모 계정 하나를 한 가족으로 센다. 테스트 구매·무료 체험·구매 의향·유료 시험 초대 신청은 결제로 세지 않는다. 전액 환불한 가족은 목표 집계에서 제외하고 환불 현황을 별도 기록한다.
- 같은 계정의 여러 과제·기기·반복 확인은 중복 집계하지 않는다. 개발·QA·운영자 테스트 계정은 제외한다.
- 첫 사용은 아이 공부 완료 후 부모 확인으로 센다. 누적 첫 사용과 가입 후 7일 이내 활성화는 구분하며, 둘 다 유료 가족 수와 별도 지표다.
- 반복 사용은 measurement.md에 따라 활성화한 주의 다음 한국 시간 월요일부터 1주 동안 서로 다른 2일 이상 핵심 흐름을 사용한 가족으로 본다. 관찰 기간이 끝나지 않은 가족은 판정을 보류한다. 반복 사용 가족 수와 관찰 완료 가족 수를 함께 보고한다.
- 유료 고객 확보 전에 소수 체험 가족의 반복 사용과 구체적인 효용을 확인한다. 20명 전원 결제나 특정 전환율을 가정하지 않는다. 필요하면 체험자를 추가 모집한다.
- 구독 상품이라면 갱신 시점이 도래한 가족의 재결제·취소·환불을 별도로 살핀다. 첫 결제 20가족만으로 장기 유지나 수익성을 입증했다고 표현하지 않는다.
- 부모 확인 결과에 따른 관리 흐름 집계는 measurement.md를 따른다. 이는 학업 성취나 정답 여부의 지표가 아니다.
- 현재 신청·가입·첫 사용·반복 사용·실결제 실적은 미확인이다. 미확인을 0이나 달성 수치로 기록하지 않는다.
- 목표 기한은 미정. 기존 마케팅 키트의 12주는 과거 계획이며 이번 확정 마감일이 아니다. 배포 가능일·반복 사용·유료 전환을 확인한 뒤 현실적인 일정을 정한다.
- 첫 사용 100가족은 필수 선행 조건에서 제외한다. 향후 확장 지표로만 참고한다.

## 매일 운영 방식

매일 낮 12시(Asia/Seoul)에 이 채팅의 최근 진행 상황과 프로젝트 문서를 바탕으로 당일 업무를 안내한다. 완료 보고가 없는 일은 미확인으로 남겨두고, 날짜가 지났다고 다음 단계로 넘기지 않는다.

예약 갱신 완료: 기존 `100-2`의 이름과 실행 지시를 ‘쌓이다 배포·유료 20가족 — 오늘의 2시간’으로 변경했다. 매일 낮 12시, ACTIVE를 유지한다. 로컬 프로젝트를 읽는 예약이므로 실행 시간에 컴퓨터와 앱이 켜져 있어야 한다. [예약 작업 공식 안내](https://learn.chatgpt.com/docs/automations)

낮 12시에 컴퓨터를 켜지 못한 날은 편한 시간에 ‘오늘 시작하자’라고 요청하면 현재 진행 상황에 맞춰 안내한다. 자동 보충 실행은 보장하지 않는다. 그날 가능한 시간이 120분보다 짧으면 그 시간에 맞추고, 쉬었던 날의 분량을 누적하지 않는다.

업무는 핵심 3개 이내와 짧은 마무리 기록으로 구성한다. 예상 시간 합계는 120분 이내다. 각 업무에는 목적, 구체적인 행동, 완료 증거, 막혔을 때의 대안을 붙인다. 가장 중요한 한 가지를 먼저 표시한다.

오래 걸리는 심사·빌드·인증의 대기 시간은 사용자의 작업 시간과 구분한다. 외부 대기가 생기면 사용자 모집 준비나 사용 안내 제작으로 전환한다. 미완료 일을 다음 날 전부 더하지 않고 우선순위를 다시 정한다.

매일 보고 형식:

> 완료: / 막힌 점: / 첫 사용·반복 사용·실결제 가족 수(아는 것만): / 다음에 가능한 시간:

이름·연락처·아이 정보를 채팅이나 저장소에 모으지 않고 집계 수와 필요한 익명 사례만 기록한다.

Google Play 정식 배포 심사는 사용자 확보 단계와 별도로 추적한다. 비공개 테스트 인원은 첫 사용 가족 수와 같지 않다. 신규 개인 계정에 해당하면 최소 12명이 14일 연속 비공개 테스트 참여 선택 상태를 유지한 뒤 프로덕션 액세스를 신청해야 한다. 14일 경과만으로 자동 출시되지 않는다. 실제 테스트와 피드백도 준비한다.

출처: [Google Play 공식 테스트 요구사항](https://support.google.com/googleplay/android-developer/answer/14151465?hl=ko), 2026-10-12 확인.

## 오늘의 120분 — 2026-10-13

오늘의 목표: 주소 증빙 제출 단계를 정리하고, 인증 대기와 별개로 첫 체험 준비를 진행한다.

결과 업데이트(사용자 보고): 인증 서류 제출 완료, 체험 후보 선정 완료, 사용 안내 대본 확인 미완료. 아래 표는 당초 배정 내역이다. 완료한 두 업무는 다음 안내에서 재배정하지 않는다. 승인 결과는 대기하며 다음 작업은 사용 안내 리허설 30분을 우선 배정한다. 오늘 남은 일을 추가 수행하도록 요구하거나 미완료 분량을 다음 날 120분에 더하지 않는다.

## 판단 규칙

- 신청은 있는데 설치가 적으면 설치 안내와 배포 경로부터 살핀다.
- 가입은 있는데 첫 사용이 적으면 등록·아이 사용·부모 확인 중 멈춘 위치를 고친다.
- 첫 사용은 있는데 반복 사용이 적으면 부모가 덜 하게 된 일과 새로 생긴 일을 인터뷰한다.
- 첫 20가족의 관찰 결과 없이 광고비·새 기능·콘텐츠 양을 먼저 늘리지 않는다.
- 유료 상품 제공에 필요한 결제는 반복 사용·상품 검증 후 준비한다. 사진 채점 같은 신규 기능은 유료 20가족 확보의 필수 조건으로 두지 않는다.
- 가격 의향 응답과 실제 결제를 혼동하지 않는다. 실제 구매가 적으면 유입 수 확대에 앞서 가격·효용·구매 과정의 거절 이유를 확인한다.
- 시간이 부족한 날에는 배포를 막는 일 또는 실제 사용을 막는 일 한 가지를 우선한다.
