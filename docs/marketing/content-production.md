# 콘텐츠 제작 원고

## 30초 실제 앱 영상 촬영안

이 파일은 **촬영안**이다. 실제 앱 사용 영상 파일은 아직 촬영하지 않았다. 배포 후보 빌드에서 가상 가족 계정으로 촬영하고 실명·이메일·실제 아이 정보가 보이지 않게 한다. 소개 페이지의 인터랙티브 화면은 설명용 예시이며 실제 앱 녹화로 표시하지 않는다.

| 시간    | 장면                               | 화면 자막                     | 내레이션                                     |
| ------- | ---------------------------------- | ----------------------------- | -------------------------------------------- |
| 0~4초   | 웹툰 ‘엄마 나 다 했어’ 장면        | 다 했다는 말, 어디까지일까요? | “엄마, 나 다 했어!” 그다음 확인할 일이 남죠. |
| 4~11초  | 부모가 오늘 수학 12~15쪽 등록      | 오늘 끝낼 분량을 함께 확인    | 오늘 어디까지 하면 끝인지 정해요.            |
| 11~17초 | 아이가 해당 공부 완료              | 아이 완료 ≠ 부모 확인         | 아이가 완료를 남기면,                        |
| 17~23초 | 부모가 문제집을 살피고 앱에서 확인 | 확인할 공부를 한곳에          | 부모는 실제 문제집을 살펴본 뒤 확인해요.     |
| 23~27초 | 기록·컬렉션 화면                   | 작은 실천이 차곡차곡          | 오늘 해낸 공부가 기록으로 쌓여요.            |
| 27~30초 | 로고 + 프로필 안내                 | 초1~3 Android 체험 가족 신청  | 쌓이다 프로필에서 체험을 신청해 주세요.      |

세로 영상 1080×1920을 작업 기준으로 사용. 자막은 중앙 여백 안에 크게 넣고 화면 아래 앱 UI를 가리지 않는다. 마지막에 ‘4주 무료·자동 결제 없음·배포 일정 개별 안내’. 현재 지원하지 않는 사진 채점 장면은 넣지 않는다.

## 스토어 원고

앱 이름 후보: 쌓이다 — 초등 집공부 기록

짧은 설명: 오늘 공부 분량부터 아이 완료·부모 확인까지, 우리 가족의 집공부를 차곡차곡.

본문: 쌓이다는 초등 자녀의 집공부를 부모와 아이가 함께 확인하는 앱입니다. 오늘 할 분량을 정하고, 아이가 공부를 마쳤다고 남기면 부모가 실제 문제집을 살펴본 뒤 확인합니다. 기록과 컬렉션으로 해낸 공부를 돌아보세요. 자동 채점이나 이해도 판단 기능은 제공하지 않습니다. 첫 체험은 계정당 아이 한 명을 기준으로 진행합니다.

스크린샷 촬영 순서: ① 오늘 어디까지 하면 끝인지 ② 아이가 마쳤어요, 부모 확인을 기다려요 ③ 확인할 공부를 한곳에 ④ 작은 실천이 기록과 성장으로. 실제 빌드 화면만 사용한다. 스토어 업로드 시 현재 Play Console 규격과 글자 제한을 다시 확인한다.

## 웹툰과 앱을 잇는 게시물 4개

1. ‘엄마 나 다 했어’ 뒤에는 확인 노동이 시작된다 → 앱의 부모 확인 대기 화면.
2. ‘두 장’의 기준은 서로 다를 수 있다 → 끝낼 페이지 범위를 함께 보기.
3. 아이 완료와 부모 확인은 다른 단계다 → 확인을 기다리는 문구.
4. “정말 이해했을까?”는 부모가 살펴볼 일 → 앱은 확인할 대상을 모으고 기록하는 부담을 줄임.

각 게시물 말미의 CTA를 통일하고 `?utm_campaign=pilot20&code=ig-w01`처럼 게시물별 모집 코드를 붙인다. 공개 URL 확정 전 게시하지 않는다.
