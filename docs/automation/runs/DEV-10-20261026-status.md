## 변경 동작

`PARENT_CONFIRMED`만 완료 수와 완료율에 포함한다. `CHILD_COMPLETED`와 `PARTIAL`은 확인 대기·부분 완료로 별도 집계한다. 아이 오늘 화면, 부모 요약, 주간·월간 기록과 달력, 기록 목록의 상태 표현을 맞춘다. 상태가 섞인 날짜는 부분 완료와 혼동하지 않도록 혼합으로 표시한다.

아이 수행 후 격려 조건과 예상 포인트 계산은 기존 세 상태 합계로 유지한다. 부모 확인 전 격려 문구는 모두 완료로 표현하지 않는다. 시작·이어하기·다시 하기와 저장·DB/API·포인트 지급·상태 전이 로직은 변경하지 않는다. 날짜 경과로 확인 대기를 자동 변경하지 않는다. 제외·이동·충돌 항목의 기존 집계 범위를 보존한다.
