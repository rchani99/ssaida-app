## 변경 및 검증

프로필 조회 실패 복구와 초기 설정 연속 탭·중복 저장 방지를 포함한다.
빌드 전 관련 회귀 테스트, 타입 검사, 린트와 독립 코드 검수가 통과했다.
기존 1.0.0 (4)에서 업데이트한 기기의 설치 APK 해시, 로그인·공부 완료 표시·3포인트 유지,
앱 재시작과 일반 부모 PIN 정상 진입을 확인했다.

배포 후 원격 APK의 해시·크기가 검증한 로컬 APK와 일치했고 별도 담당이 원격 릴리스 버전·노트와
기존 대상 그룹을 재확인했다. 이 기록은 실제 수신자의 이메일 수신·설치 성공을 보증하지 않는다.
신규 계정 초기 설정, 새 OAuth, 실제 프로필 통신 실패 재시도와 알림 경로 기기 검증은 남아 있다.
이번 Git 문서 정비에서 앱 검증을 다시 수행한 것은 아니다.

## 추적과 제한

이 문서는 2026-10-22 기존 코드 검수·빌드·기기·배포 실행 기록을 요약한다.
태그는 위 소스 커밋에 고정하고, 이후 문서 수정이나 미배포 기능은 별도 커밋으로 관리한다.
로컬 태그 생성과 GitHub 게시 상태는 구분하며 원격 반영에는 별도 승인이 필요하다.
EAS의 원격 버전 관리와 자동 증가를 사용하므로 소스 태그 재빌드가 같은 빌드 번호나
동일 APK를 생성한다는 뜻은 아니다. 이번 산출물은 위 빌드 ID와 APK 해시로 식별한다.
APK는 Firebase 배포를 유지하고 이 공개 Git 저장소에 첨부하지 않는다.
DB/API·패키지 식별자·서명 설정 변경은 없다. 후속 아동 홈 로딩 개선 커밋은 이 APK에 포함되지 않는다.
