운영 원칙: 반복적인 사용자 할 일 배정 대신, 조정자가 남은 작업 중 실행 가능한 결과물 하나를 선택하고 제작 담당과 검수 담당에게 구체적으로 위임한다. 독립 보조 검토에서 아래 완료 기준·상태 관리·중복 방지 보완점을 확인했다. 이 검토는 영구 실행이나 예약 실행 성공의 증거가 아니다.

- 조정자: 최신 사용자 지시와 증거를 대조하고 작업을 선택·배정하며 최종 합본과 작업표를 갱신한다.
- 제작/개발/조사 담당: 문서는 원고와 근거를 반환하고, 개발은 조정자가 지정한 격리 작업 디렉터리와 소유 파일에서 실제 코드를 구현한다. 다른 담당과 같은 파일을 동시에 수정하지 않는다. 사용자의 미완료 변경을 덮어쓰지 않는다.
- 검수 담당: 실제 제공 기능, 날짜·근거, 미확인 정보, 과장된 마케팅 표현, 완료 기준 충족 여부를 검사한다. 제작 담당 자신의 검수를 독립 검수라고 표시하지 않는다.
- 자원 범위: 조정자 1명과 동시 보조 최대 2명, 하위 에이전트의 추가 생성 금지. 한 실행당 주 결과물 1개, 검수 수정 최대 2회, 같은 도구 실패 재시도 최대 1회. 계정·예산 한도 도달 시 상태를 저장한다. 별도 유료 API·클라우드 자원 구매는 이 요청만으로 실행하지 않는다. 보조 도구가 없는 실행은 검수대기로 기록하며 조정자의 자체 점검을 독립 검수로 표시하지 않는다.
- 상태: 준비 / 실행 중 / 검수 중 / 검수 완료 / 입력 대기 / 외부 실행 대기. 작업 ID·입력 근거·갱신일·담당·결과 경로·검수 결과·다음 조건·재시도 횟수를 기록한다. 중단된 실행은 파일과 결과부터 대조하고 외부 작업을 무조건 재실행하지 않는다.

## 이전 목표의 판단 규칙 — 현재 목표와 충돌하면 적용하지 않음

- 신청은 있는데 설치가 적으면 설치 안내와 배포 경로부터 살핀다.

- 시간이 부족한 날에는 배포를 막는 일 또는 실제 사용을 막는 일 한 가지를 우선한다.

## 기기 접근성과 설치 마찰 — 2026-10-19 대화 후속

근거: 사용자가 아이의 개인폰·태블릿 등 실제 사용 기기가 불확실하고 Family Link 기기 설치 자체가 어려웠다고 보고했다. 아이가 공부할 때 바로 사용할 기기가 있다는 전제는 미검증이다. 한 기기의 경험을 모든 감독 계정의 제한으로 일반화하지 않는다.

다음 우선 결과물: (1) 설치한 기기에서 같은 가족 연결·아이 완료·부모 확인 검증 기록, (2) 기존 후보 5가정의 기기 환경 확인표, (3) 기기 환경 질문 스토리 원고와 기존 릴스 반응 기록. Family Link 로그인 성공 단계는 Firebase 배포 페이지인지 쌓이다 내부인지 먼저 구분한다. 부모 폰 단독 사용은 검토 가설이며 구현·검증 완료로 표현하지 않는다. 본인 기기 테스트는 체험 가족 수에서 제외한다.

권장 작업량은 첫 사용 확인 45분, 후보 기기 환경 확인 준비/가능한 응답 정리 30분, 스토리 게시 준비와 릴스 반응 확인 25분, 완료 보고 10분으로 총 110분이다. 첫 사용이 막히면 오류 화면과 단계를 남기고, 후보 응답이 없으면 미응답으로 둔다. 인스타 수치가 보이지 않으면 미확인으로 둔다. 외부 메시지·게시는 이 예약에서 실행하지 않는다.
