# 쌓이다 사용 안내 영상 제작안

작성일: 2026-10-12. 형식: 실제 앱 화면 녹화 + 한국어 자막 + 한국어 내레이션.
상태: 현재 소스의 화면 이름과 동작을 확인한 촬영 대본. 실제 영상·음성 파일은 아직 제작하지 않았다.
시간은 편집 목표이며 실제 조작과 낭독 길이를 보고 조정한다.

## 전달할 경험

부모가 문제집 하나를 등록하고, 아이가 오늘 할 공부를 확인해 시작하고, 부모가 공부 결과를 확인하는 하루를 따라 한다. 시청 후 자신의 문제집 하나를 등록할 수 있게 만드는 것이 목표다.

첫날부터 모든 공부를 등록하도록 권하지 않는다. 아이와 부담 없는 분량을 정하고 한 과목부터 시작하도록 안내한다. 습관 형성이나 잔소리 감소를 보장하는 문구는 사용하지 않는다.

## 영상 구성

| 순서 | 제목 | 대상·목표 | 목표 길이 |
| --- | --- | --- | --- |
| 1 | 처음이라면, 문제집 하나로 시작해요 | 부모: 등록부터 부모 확인까지 첫 사용 | 약 3분 |
| 2 | 오늘 공부하고 내 친구 키우기 | 아이: 시작 → 완료 → 부모 확인 → 정원 | 약 40초 |
| 3 | 계획한 만큼 못 했을 때 | 부모: 실제로 공부한 분량 확인 | 약 50초 |

1편을 먼저 제작한다. 2편은 1편의 아이 화면을 활용하고, 3편은 별도의 예시 공부를 촬영한다. 로그인·가입은 첫 영상의 시작 조건으로 짧게 안내하고, 계정 설정 과정 전체가 필요하면 별도 도움말로 만든다.

## 1편 — 처음이라면, 문제집 하나로 시작해요

시작 조건: 로그인과 아이 이름·하루 목표시간·부모 PIN 설정이 끝난 상태. 이 조건을 영상 첫 부분과 설명란에 표시한다. 예시 가족과 예시 문제집을 사용한다.

| 시간 | 촬영 화면·조작 | 화면 자막 | 내레이션 |
| --- | --- | --- | --- |
| 0:00–0:12 | 오늘 공부 화면. 제목을 짧게 표시 | 처음에는 문제집 하나부터 | 쌓이다가 처음이라면, 아이와 문제집 하나부터 시작해 보세요. 공부를 등록하고, 아이가 마친 뒤, 부모님이 확인하는 과정을 함께 해볼게요. |
| 0:12–0:27 | 부모님 메뉴 → PIN 확인 → 부모 대시보드. PIN 입력 부분은 편집으로 생략 | 로그인과 아이 설정 후 따라 해주세요 | 로그인과 아이 설정을 마쳤다면, 부모님 메뉴에서 설정한 PIN으로 들어가 주세요. 공부 등록은 부모님 화면에서 할 수 있어요. |
| 0:27–0:45 | 공부 관리 → + 공부 등록 → 문제집 → 공부 이름 | 공부 관리 → + 공부 등록 | 공부 관리에서 공부 등록을 누르고, 문제집을 선택해요. 아이가 알아보기 쉬운 이름을 적어주세요. 여기서는 수학 문제집으로 해볼게요. |
| 0:45–1:06 | 예상 소요시간 10분, 공부 요일 선택. 과목은 선택 사항으로 표시 | 시간과 공부할 요일 정하기 | 대략 걸릴 시간과 공부할 요일을 정해요. 처음에는 아이와 무리 없이 해볼 수 있는 분량으로 시작해 주세요. 과목은 필요하면 선택할 수 있어요. |
| 1:06–1:32 | 다음 시작 페이지 12, 한 번에 풀 페이지 2, 마지막 페이지 100 입력. 등록하기 탭 | 다음 시작 12 / 한 번에 2 / 마지막 100 | 다음 시작 페이지는 이제 풀 차례인 쪽이에요. 12쪽부터 두 쪽을 풀려면 이렇게 입력해요. 마지막 페이지는 오늘 끝낼 쪽이 아니라, 이 문제집에서 공부할 마지막 쪽이에요. 입력을 마치면 등록하기를 눌러요. |
| 1:32–1:47 | 아이 화면 → 오늘 목록의 수학 문제집 12~13쪽 | 아이와 오늘 할 분량 확인하기 | 아이 화면으로 돌아와 오늘 공부를 함께 봐요. 이 예시에서는 수학 12쪽부터 13쪽까지예요. 시작하기 전에 어디까지 할지 함께 확인해 주세요. |
| 1:47–2:04 | 공부 시작 → 공부하기 화면. 실제 공부 시간은 컷 전환 → 완료 | 공부 시작 → 실제 공부 → 완료 | 아이가 공부 시작을 누르고 문제집을 풀어요. 공부를 마쳤을 때 완료를 눌러주세요. 영상에서는 공부하는 시간을 잠깐 건너뛸게요. |
| 2:04–2:16 | 부모 확인 대기 문구를 확대 | 이제 부모님이 확인할 차례 | 아이가 완료를 누르면 부모님 확인을 기다리게 돼요. 아이가 마쳤다는 표시와 부모님이 확인한 기록은 구분되어 있어요. |
| 2:16–2:42 | 부모님 메뉴 → PIN → 대시보드 확인 필요 → 해당 문제집. 계획대로·13쪽 확인 후 확인 탭 | 실제 문제집 확인 → 계획대로 → 확인 | 부모님 화면의 확인 필요를 열고, 실제 문제집을 살펴봐 주세요. 계획한 분량을 했다면 계획대로를 선택하고 끝낸 쪽을 확인한 뒤, 확인을 눌러요. 앱이 자동으로 채점하는 과정은 아니에요. |
| 2:42–2:54 | 아이 화면 → 정원. 미선택 상태라면 테마 선택 화면도 표시 | 정원에서 성장을 함께 확인해요 | 아이와 정원에서 성장을 확인해 보세요. 아직 테마를 고르지 않았다면, 키우고 싶은 친구의 테마부터 선택해 주세요. |
| 2:54–3:05 | 오늘 공부 화면과 마무리 카드 | 오늘은 문제집 하나만 등록해 보세요 | 처음부터 모든 공부를 넣을 필요는 없어요. 오늘은 문제집 하나로 시작하고, 아이가 해낸 일을 함께 이야기해 주세요. |

### 촬영 준비

- 예시 아이 이름은 ‘하루’, 공부 이름은 ‘수학 문제집’으로 통일한다.
- 로그인·온보딩 완료 상태, 진행 중인 다른 공부가 없는 예시 계정을 준비한다.
- 공부 요일에 촬영 당일을 포함하고, 촬영 당일이 휴식일이 아닌지 확인한다.
- 예시 값 12·2·100은 촬영용이다. 시청자에게 자신의 문제집에 맞게 입력하도록 설명란에 적는다.
- 등록 후 오늘 목록에 12~13쪽이 실제로 생성되는지 먼저 리허설한다. 나오지 않으면 원인을 확인하고 실제 필요한 조작을 촬영안에 반영한다. 조작을 생략해 즉시 나타나는 것처럼 편집하지 않는다.
- 정원 장면은 같은 계정의 실제 부모 확인 결과를 사용한다. 공부 한 번으로 수집물이 완성되는 것처럼 연출하지 않는다. 성장 전후 차이가 작으면 실제 수치·게이지를 확대한다.
- PIN 입력, 계정 이메일, 개인 알림은 녹화에 노출하지 않는다.

## 2편 — 오늘 공부하고 내 친구 키우기

시작 조건: 부모가 공부를 등록했고, 아이 화면에 오늘 할 일이 있는 상태.

| 시간 | 화면 | 자막·내레이션 |
| --- | --- | --- |
| 0:00–0:08 | 오늘 공부의 이름과 페이지 | 오늘 할 공부를 같이 볼까? 어디까지 할지 먼저 확인해 봐. |
| 0:08–0:17 | 공부 시작 → 공부하기 | 준비됐으면 공부 시작! 이제 문제집을 풀어보자. |
| 0:17–0:25 | 공부 시간 컷 전환 → 완료 | 공부를 마쳤다면 완료를 눌러줘. |
| 0:25–0:32 | 부모 확인 대기 화면 | 이제 부모님께 공부한 걸 보여드리자. |
| 0:32–0:42 | 실제 부모 확인 후 정원 | 부모님이 확인하면 친구가 조금씩 자라. 오늘 해낸 공부를 함께 돌아보자! |

## 3편 — 계획한 만큼 못 했을 때

범위: 아이가 완료를 눌렀지만 실제로는 일부 분량만 공부한 경우. 시작하지 않은 공부·이월·진도 충돌은 이 영상의 범위에 포함하지 않는다.

| 시간 | 화면 | 자막·내레이션 |
| --- | --- | --- |
| 0:00–0:10 | 계획 12~15쪽인 별도 예시 공부 | 계획보다 적게 공부했다면, 실제로 한 만큼 기록할 수 있어요. |
| 0:10–0:20 | 부모 화면 → 확인 필요 → 해당 공부 | 아이가 완료를 누른 공부를 열고, 실제 문제집을 확인해 주세요. |
| 0:20–0:35 | 조금만 선택 → 몇 쪽까지 했나요?에 13 입력 | 15쪽까지가 계획이었지만 13쪽까지 했다면, 조금만을 고르고 13을 입력해요. |
| 0:35–0:45 | 확인 → 저장 결과 | 확인을 누르면 실제로 공부한 쪽까지 기록돼요. |
| 0:45–0:52 | 마무리 카드 | 기록한 뒤에는 아이와 다음 공부 분량을 함께 이야기해 주세요. |

## 자막·음성·편집 기준

- 세로 앱 화면을 기준으로 편집한다. 화면 비율을 유지하고, 자막은 터치할 버튼을 가리지 않는 별도 여백에 배치한다.
- 내레이션은 차분한 대화체로 읽는다. 버튼 이름은 화면 문구와 똑같이 읽고, 누르기 전후 화면을 충분히 보여준다.
- 주요 자막은 한 장면에 한 행동, 최대 두 줄로 만든다. 음성 전체를 담는 선택형 자막 파일은 편집 확정 후 실제 타임코드에 맞춰 제작한다.
- 터치 위치를 원으로 표시하고, 페이지 입력과 부모 확인은 확대한다. 중요한 조작은 배속하지 않는다.
- 공부한 시간을 생략할 때에는 ‘공부를 마친 뒤’ 자막을 넣어 시간 경과를 알린다.
- 배경음악은 없어도 된다. 사용한다면 목소리를 가리지 않도록 낮춘다.

## 제공 방식 제안

처음에는 안내 영상 링크와 짧은 글 안내를 체험 설치 안내문에 함께 제공한다. 1편 설명란에 ‘공부 등록’, ‘아이 공부’, ‘부모 확인’, ‘정원’의 최종 영상 타임코드를 넣어 필요한 부분을 다시 찾을 수 있게 한다.

앱 내 배치 후보는 설정의 ‘사용 방법’과 첫 공부가 없는 화면의 ‘처음 시작하기’다. 이는 제안이며 현재 앱에 추가한 기능은 아니다. 자동 재생이나 필수 시청은 적용하지 않는다.

업로드 제목: `쌓이다 처음 사용하기 | 문제집 등록부터 부모 확인까지`

설명란 초안:

> 아이와 문제집 하나부터 시작해 보세요. 이 영상은 로그인과 아이 설정을 마친 뒤, 공부 등록부터 부모 확인까지 따라 하는 안내입니다. 예시 페이지와 시간은 우리 아이의 문제집에 맞게 바꿔주세요. 공부 결과는 부모님이 실제 문제집을 살펴본 뒤 확인합니다.

## 완료 기준과 남은 작업

대본은 소스에 있는 버튼 이름·입력 필드·확인 흐름을 기준으로 작성했다. 실제 기기에서의 촬영 리허설과 영상 검수는 아직 하지 않았다.

다음 제작 순서: 실제 기기 리허설 → 화면 녹화 → 내레이션 녹음 또는 음성 제작 → 자막·편집 → 휴대폰 전체 화면으로 검수 → 최종 MP4와 자막 파일 출력. 공개 업로드와 앱 내 연결은 제작 후 별도 작업이다.

처음 쓰는 부모가 영상만 보고 문제집 등록과 부모 확인을 완료하는지 관찰한다. 막힌 화면을 먼저 고치고, 같은 설명을 영상에 반복해서 추가하는 방식으로 해결하지 않는다.
