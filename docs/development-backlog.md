## 보고와 상태 갱신 양식

각 실행의 결과 문서에는 과제 ID/제목, 상태와 세부 단계, 승인 근거, 기준 SHA/작업 경로,
변경 파일, DB/API 변경 사항, 테스트 명령·결과·미실행 범위, 독립 검수 결과, 발견 문제,

정책 충돌이 생기면 해당 항목을 BLOCKED로 두고 [제품 결정](product-decisions.md)에 차이를 연결한다.
