# 반복 사용·가격 검증 운영

## 15~20분 인터뷰

1. 앱을 쓰기 전, 어제 아이 문제집 관리를 어떻게 했나요?
2. 쌓이다를 최근 사용한 날의 행동을 순서대로 이야기해 주세요.
3. 첫 공부 등록→아이 완료→부모 확인 중 어디서 멈췄나요?
4. 다시 안 켠 날에는 어떤 이유가 있었나요?
5. 실제로 덜 하게 된 일과 새로 생긴 일이 있나요? 구체적인 날을 떠올려 주세요.
6. 없어지면 가장 아쉬울 기능 하나, 없어도 되는 기능 하나는 무엇인가요?

감사비는 응답의 긍정 여부·후기·평점과 무관하게 지급. 기본 인터뷰에서 가격을 암시하거나 답을 유도하지 않는다. 부모가 직접 말한 표현, 실제 행동, 운영자의 해석을 구분해 기록한다.

## A/B 제안 카드 (현재 제공 여부 명확히)

### A · 월 2,900원

오늘 계획, 아이 완료, 부모 확인, 기록, 컬렉션을 월 구독으로 사용합니다. **검증용 구성·가격이며 지금 결제하지 않습니다.** 유료 시험이 준비되면 초대를 받으시겠어요?

### B · 월 4,900원

기본 관리 기능 무료 + 문제집 사진의 빈칸 확인·정답지 대조 채점 보조 월 30쪽. 초등 수학 객관식·숫자 단답형부터 검토합니다. 정답지 제공이 필요하며 불명확한 답은 부모가 다시 확인합니다. 서술형과 이해도 판단은 포함하지 않습니다. **아직 없는 기능이며 아래는 개념 설명입니다. 출시·정확도·시간 절감은 미확정입니다.** 유료 시험이 준비되면 초대를 받으시겠어요?

예시 화면 텍스트: `사진 촬영 → 정답지 연결 → 1번 정답 후보 / 2번 판독 어려움: 부모 확인 / 3번 답안 미검출: 빈칸 여부 확인 → 부모 수정·확정`. 실제 분석 결과나 정확도 수치처럼 제시하지 않는다.

## 제시·집계

- 핵심 흐름 3회 이상인 서로 다른 부모 20명. 운영표 20개 슬롯의 홀수 AB, 짝수 BA를 유지한다. 먼저 보여줄 카드는 미리 정해 부모 반응에 따라 바꾸지 않는다.
- 두 제안을 모두 본 뒤 **A 신청 / B 신청 / 둘 다 신청하지 않음** 중 하나와 이유를 받는다.
- 신청의 의미: 가격을 확인했고, 해당 유료 시험 초대를 요청함. 결제·예약금 수취 없음.
- 한 안 6명 이상이면 선택. 둘 다면 신청 수가 많은 안, 동률 A. 둘 다 6명 미만이면 개발·광고 확대를 보류하고 가장 흔한 거절 이유를 개선해 한 번 더 검증.
- 20명 미만 또는 제시 순서가 10:10이 아니면 확정 결정을 미룬다. 내부 기준이며 일반적인 시장 수요로 추정하지 않는다.
- 가격 설문 통과 후 실제 5가족 결제가 없으면 거절 이유 재확인. 결제 불가한 상태에서 가짜 구매 버튼으로 결제를 암시하지 않는다.

## B가 선정된 경우에만 할 실험

유사 난이도·분량의 초등 수학 페이지를 준비하고 직접 채점과 보조 방식의 순서를 번갈아 측정한다. 실제 촬영·재촬영·정답지 준비·업로드·대기·부모 수정·확정까지 시간을 기록한다. 한 쪽의 수동 채점 시간을 뺀 값이 아니라 **총 소요 시간끼리** 비교한다. 사진 사용 동의·저장 기간·삭제 경로는 실험 설계 단계에 별도 확정한다.

기록: 가족 코드, 페이지 유형, 답 수, 판독 어려운 답 수, 잘못 판단한 답 수, 재촬영 횟수, 수동 총 초, 보조 총 초, 부모 수정 초, 처리 비용 원, 부모의 재사용 의사. 작은 표본의 평균만 보지 말고 각 가족의 시간 변화도 확인한다.

월 30쪽을 모두 쓴 경우의 처리 비용, 실제 스토어 수수료, 서버·지원 비용을 포함한 수익이 양수이고 부모의 총 시간이 줄어드는지 확인한다. 이익 또는 시간 절감이 확인되지 않으면 B 유료 출시 보류. 사진 인터페이스와 모델 선정은 그때 설계한다.

## 선정 후 결제 구현 범위

Google Play 실결제는 서버가 구매 토큰을 검증한 뒤 구독 권한을 부여한다. 클라이언트 성공 표시만 신뢰하지 않는다. 구매·중복 콜백·복원·갱신·유예/보류·만료·취소·환불/철회와 다른 계정 복원 충돌을 검증한다. 스토어 테스트 결제는 유료 고객에서 제외한다. 이벤트 원문과 비밀키를 운영표에 넣지 않는다.

신청자에게 유료 상품을 제공할 수 있을 때만 실제 결제를 시작한다. 영구 무료나 사진 기능을 미리 약속하지 않는다.
