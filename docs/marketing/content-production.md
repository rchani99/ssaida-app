2026-10-19 추가 사용자 보고: 인스타 웹툰은 **3화까지 게시 완료**. 게시 사실은 사용자 보고 근거이며 이번 작업에서 원본·각 화의 줄거리·반응을 직접 확인하지 않았다. 웹툰을 새 콘텐츠 일정에서 빠뜨리지 않는다. **주 4개 게시물 안에 웹툰 1화, 보조 카드 1개, 릴스 2개를 포함**하는 안으로 보완한다. 웹툰을 별도 추가 숙제로 쌓지 않는다.

웹툰의 역할은 부모의 공감과 다음 이야기에 대한 관심, 앱 영상은 기능 이해, 보조 카드는 궁금증 해소·체험 안내다. 주 1회 4화부터 연재를 이어가되 1~3화의 내용·캐릭터·말투를 확인한 뒤 다음 화를 정한다. 매화 앱으로 문제를 해결하는 결말이나 모집 광고를 억지로 붙이지 않는다. 기존 컷을 활용한 릴스도 장면·권리·개인정보 검토 후 제작하며 재활용 자체가 새 게시 완료를 뜻하지 않는다. 지난 화는 스토리로 소개하고 가능한 계정 기능에 맞춰 모아보기 경로를 준비한다.

제작량이 하루 120분을 초과하면 보조 카드 1개를 줄여 웹툰 1화+릴스 2개로 시작한다. 조회·저장·공유·구체적 공감 반응은 관심 지표, 프로필 방문·체험 문의는 다음 행동 지표로 나누며 웹툰 한 편의 직접 신청 수만으로 연재 중단을 결정하지 않는다.

### 신청까지 이어지는 경로

- 설치 전: 게시물 → 프로필의 준비 안내 → 문의 또는 대기 신청. 아직 설치할 수 없으면 ‘지금 다운로드’라고 안내하지 않는다. 비공개 사이트 링크는 대중에게 배포하지 않는다.
- 준비 후: 게시물/허용 커뮤니티 → 공개 소개·신청 한 곳 → Android·학년·참여 일정 확인 → 사용자가 참여 확정 → Firebase 설치 안내 → 첫 사용 지원.
- 앱 테스트는 10가정·14일이며 시작일·테스트 비용과 보상은 미확정이다. 기존 문서·사이트의 ‘4주 무료’를 그대로 재사용하지 않는다. 테스트 목적, 실제 사용 데이터와 설문 수집, 중단·문의 방법을 게시 전에 명확히 한다. 긍정 후기·평점을 참여 조건으로 삼지 않는다.
- 링크가 준비되지 않았을 때의 CTA: ‘체험 준비 소식이 궁금하면 @ssaida.app에 메시지로 알려 주세요.’ 연락처나 자녀 정보를 공개 댓글에 남기게 하지 않는다. 링크가 준비되면 프로필의 한 신청 링크로 통일한다.

### 주간 판단과 하루 120분

채널·게시물 코드별 도달(볼 수 있는 경우), 프로필 방문·링크 클릭, 대상에 맞는 문의, 참여 동의, 설치, 첫 사용을 기록한다. 알 수 없는 값은 미확인, 분모가 0이면 전환율은 계산하지 않는다. 적은 표본에서 작은 수치 차이로 승자를 확정하지 않는다.

- 도달은 있으나 문의가 없으면 첫 화면의 문제 제기·대상·설명을 바꾼다.
- 문의는 있으나 참여가 적으면 대상 조건·일정·사용 부담·설명에서 막힌 이유를 확인한다.
- 참여했으나 설치하지 않으면 게시물 수를 늘리기보다 설치 안내를 고친다.
- 첫 사용 후 떠나면 모집량 확대보다 제품과 지원을 개선한다.
- 7일마다 최대 2개 모집 채널과 2개 메시지의 근거를 비교한다. 노출 기회가 거의 없거나 규정 확인이 안 된 채널은 효과 없음이 아니라 평가 불가다.

권장 하루 배분: 준비된 콘텐츠 확인·게시 25분, 허용 채널 확인·응대 35분, 체험 배포/가족 지원 45분, 기록·다음 우선순위 15분. 실제 게시·외부 연락은 사용자가 직접 하거나 구체적으로 허용한 때만 실행한다. Codex는 사용자가 검토 가능한 완성 원고·조사 근거·답변 초안을 먼저 만든다.

### 2026-10-22 Metricool 무료 게시 연결 재개 — 연결 대기

사용자가 기존 연결·카드5장 전달·승인 후 게시 작업을 완료하도록 요청했다. 최신 플러그인 조회는 Metricool installed=false이며 호출 가능한 Metricool 도구가 없었다. 접근 가능한 브라우저 목록에도 사용자의 Chrome이 없어 기존 로그인 세션을 검사하지 못했다. 사용자에게 설치·계정 연결 완료를 요청했고, 실제 연동 성공으로 처리하지 않았다.

독립 준비 완료: CONTENT-01 v2를 `outputs/instagram-card-01/revision-2/`에 저장. 현재 계정 @ssaida.app으로 이미지5장·캡션·대체텍스트를 수정했으며 기존 v1은 보존했다. 렌더 검증과 조정자 시각 검토 통과. 새 버전의 독립 검수를 수행한 것은 아니다. `publishing-state.json`에 파일 순서·SHA256·승인/원격초안/게시 미실행 상태를 기록했다.

무료 운영 경로는 이 채팅 결과 보고 → 특정 버전·계정·시각에 대한 사용자 승인 → Metricool 게시 → 상태/URL 확인이다. Metricool 자체 이메일 검토·승인은 Advanced/Custom 기능임을 공식 도움말로 재확인했다. 이메일 승인 기능을 무료로 구축했다고 하지 않는다. 알림 전달·원격 파일 업로드·초안 생성·실제 게시는 아직 검증 전이다. 연결 후 먼저 현재 연결된 계정과 도구의 지원 기능을 확인한다. 이번 작업 요청은 최종 수정본의 게시 승인으로 기록하지 않았다.

### 2026-10-22 Metricool 연결 직접 확인

ssaida.app 연결을 사용한 인증된 브랜드 조회 성공. 반환된 브랜드 ID는 7577468, Instagram은 ssaida.app, 시간대는 Asia/Seoul이다. 이전 미연결 기록은 이력이며 현재 계정 조회 연결은 확인됐다. 원격 초안·파일 업로드·게시 성공은 아직 검증하지 않았다. 카드 CONTENT-01 v2의 사용자 게시 승인은 여전히 미기록이다. 개인 이메일·토큰 등은 저장하지 않았다.


### 2026-10-22 CONTENT-01 v2 Metricool 초안 저장 완료
