최신 운영 기준(2026-10-12): **쌓이다를 배포하고, 반복 사용을 확인한 뒤 실제 유료 고객 20가족을 확보한다.** 하루 2시간, 매일 낮 12시(한국 시간) 안내로 운영하며 [현재 운영 계획](launch-paid-20-daily-plan.md)을 우선한다. 체험 5가족 → 체험 20가족 → 유료 5가족 → 유료 20가족 순서로 진행한다. 첫 사용 100가족은 필수 목표에서 제외했다.

## 배포 준비와 일정

Google Play 계정은 아직 없다. 신규 개인 계정은 현재 공식 기준으로 **최소 12명이 14일 연속 비공개 테스트 참여 선택 상태를 유지**한 뒤 프로덕션 접근을 신청해야 한다. 14일이 지나면 자동 출시되는 것은 아니다. 등록 수수료는 1회 US$25이며 마케팅 월 10만원과 별도의 출시 비용으로 기록한다. 계정 유형은 실제 사업/개인 상태에 맞춰 선택한다. [계정 개설 안내](https://support.google.com/googleplay/android-developer/answer/6112435?hl=ko), [테스트 요구사항](https://support.google.com/googleplay/android-developer/answer/14151465?hl=ko) (2026-10-09 확인)

배포 전 운영 서버, 계정 삭제, 정식 콘텐츠, 실기기 핵심 흐름을 점검한다. 결제·사진 기능 개발은 아직 시작하지 않는다. 초기 20가족과 가격 유효 응답 20명은 다를 수 있으므로, 이탈하면 적합한 체험자를 추가 모집한다. 4주차에 유효 20명이 안 모이면 결정을 연기한다.

| 시점    | 작업                              | 판단                                 |
| ------- | --------------------------------- | ------------------------------------ |
| 배포 전 | 페이지·신청·모집문·영상·측정 준비 | 신청부터 설치 안내까지 점검          |
| 1~2주   | 20가족 모집·첫 사용 지원          | 등록→아이 완료→부모 확인의 막힘 기록 |
| 3~4주   | 반복 사용·주 2건 인터뷰·가격 제안 | 유효 20명, 제시 순서 절반씩          |
| 5~8주   | 선정 상품만 최소 구현·실결제 시험 | 실제 결제 5가족·환불·문의 원인 확인  |
| 9~12주  | 성과 경로 집중·동의 사례·소개     | 누적 결제 20가족·도래자의 갱신 확인  |

운영 주 4시간: 콘텐츠 1시간, 모집·응답 1시간, 인터뷰 2건과 정리 1시간, 지원·주간 검토 1시간. 마케팅 월 최대 100,000원: 감사비 50,000원(긍정 후기·평점과 무관), 소개 도구 20,000원, 반복 사용 확인 후 광고 30,000원. 자연 유입이 검증되기 전 광고비를 쓰지 않는다.

## 공개 전 체크

- [ ] 공개 모집용 공유 범위와 URL 확인(비공개 검수 URL을 프로필에 붙이지 않기)
- [ ] 실제 신청 1건을 본인 정보로 제출하고 조회·삭제까지 점검
- [ ] `QA-EXCLUDE` 가상 신청 정리 (실제 체험 가족 아님)
- [ ] 인스타그램 DM 수신 및 신청 철회·삭제 요청 대응 담당 확인
- [ ] 보관 만료일 매주 점검, 90일 이내 삭제(서버는 새 신청 시 만료 자료 정리도 수행)
- [ ] 지원 이메일을 만든 뒤 사이트·Play 등록정보·안내문 함께 갱신
- [ ] 설치 링크는 빌드 준비 후 삽입. 임시·추측 URL 금지
- [ ] 커뮤니티 게시 허용 여부 확인, 개발자임을 밝히기
- [ ] 30초 영상 실제 앱 촬영 및 스토어 스크린샷 준비

운영표 입력 범위는 가족 100행·결제 200행이다. 범위를 넘으면 집계 수식을 확장한다. 개인정보는 버전 관리에 넣지 않는다. 실적이 없는 칸은 비워 두고 추측 수치를 채우지 않는다.
